# Weather Dashboard

## Overview

A responsive Weather Dashboard that allows users to search for any city and view:

* Current weather conditions
* 5-day weather forecast
* Hourly temperature chart
* Dynamic weather information using Open-Meteo APIs

---

## Features

### Current Weather

Displays:

* City and Country
* Current Temperature
* Feels Like Temperature
* Weather Condition
* Weather Icon
* Humidity
* Wind Speed
* Visibility

### 5-Day Forecast

Shows:

* Day Name
* Weather Icon
* Maximum Temperature
* Minimum Temperature

### Hourly Temperature Chart

* Built using Chart.js
* Displays hourly temperatures
* Current hour highlighted

### Error Handling

* Invalid city detection
* API failure messages
* Non-crashing user experience

### Loading State

* Loading spinner
* Disabled search button during requests

### Stretch Features

* Temperature Unit Toggle (°C / °F)
* Geolocation-based weather
* Dynamic weather backgrounds
* LocalStorage for last searched city

---

## API Used

### Open-Meteo Geocoding API

Used to convert city names into coordinates.

### Open-Meteo Forecast API

Used to retrieve:

* Current weather
* Hourly temperatures
* Daily forecast

No API key required.

---

## Tech Stack

* HTML5
* CSS3
* JavaScript (ES6)
* Chart.js
* Open-Meteo APIs
* LocalStorage

---

## Setup Instructions

1. Download or clone the repository.

2. Open the project folder in VS Code.

3. Install Live Server extension.

4. Open index.html using Live Server.

5. Search for any city to view weather information.
